Rescue a stuck FM-1

for developers

No installer finds the FM-1 any more, or an update stopped and it will not come back? Its chip has a bootloader in ROM that no firmware can overwrite. FM-1 rescue: step by step for Windows, Mac and Linux, by what you see. Here: the button that sends it there (any computer, Chrome or Edge), and two commands for Linux.

Show the rescue steps

The screen stops and the computer sees a USB disk "UBOOT1.00". Nothing is written yet: switching the FM-1 off and on brings it back as it was.

curl -fsSLO https://thefirmwarehub.com/rescue/fm1_rescue.py
sudo python3 fm1_rescue.py sloop

It checks before it writes: the chip, the flash, the chip key, the package. It writes only the firmware area, never the bootloader, reads every sector back and restarts the FM-1. --check only looks. fm1_rescue.py (GPL-3.0), the bootloader protocol after jl-uboot-tool (MIT), whose flash helper for the chip it downloads.

On a Mac: M-Flasher, step by step. On Windows, or with a full backup first: MvaveFM1Unbricker by Quixotic7 (MIT) takes the same way in. It reads the whole flash twice and keeps it, writes only the firmware area and checks every byte. An FM-1 that never shows "UBOOT1.00" at all comes back with its Transporter guide and a small RP2040 board.

How do I install a firmware on the FM-1?

In Chrome or Edge (they speak Web MIDI): connect the FM-1 by USB, press Connect FM-1, then Install on the firmware you want. About a minute, the FM-1 restarts as a different instrument. No app, no driver, no file to download.

Why only open-source firmwares?

The hub lists firmwares that are free software, released with their source (GPL-3.0): so every package can be mirrored unchanged, checked and kept available, and anyone can see what it does. Closed or paid firmwares are not listed. The one exception is M-VAVE's own FM1 Open, shown as the official firmware: its app is GPL-3.0, its sound engine closed source (a binary SDK), and it installs from M-VAVE's Workbench, not from the hub.

Why is Baud Girl only a link? Where is Groove OS?

Both are fine firmwares for the FM-1, but neither is open source: there is no published source and no license that allows passing the package on, so this page may not mirror them. Baud Girl is asked for so often that it has a card anyway: the button takes you to Madeline's own installer (free, tips on Ko-fi). Groove OS installs from groove-os.com. If either becomes open source with a release on GitHub, it goes on here like the others.

Is it always the newest version?

Yes. Every night the hub looks at each project's repository and offers its newest release, after checking that the package is an FM-1 firmware with the update loader. Betas are marked.

How do I go back to the official firmware?

Press Back to official V15 in the box above: M-VAVE's own file from its repository, served unchanged and checked byte for byte (or choose V15 downloaded from m-vave.com there). If the FM-1 is stuck, hold OCT− while switching it on (USB rescue) and install again; if no installer finds it at all, rescue it with a hub firmware first.

Are the firmwares safe to flash?

Every firmware here is open source, and every package is built by GitHub Actions straight from its public code – the card links the exact commit and its build log, and GitHub's signature proves the file came from there. The hub checks each package before it offers it: an FM-1 firmware with the FM-1's update loader, nothing else. And nothing can lock you out: the FM-1's bootloader sits in ROM, no firmware can overwrite it, and Back to official V15 or the Rescue always bring it back. What a firmware does once it runs is up to its maker – its code is there for anyone to read.

My FM-1 says "save error" – or saves are gone after switching off. A newer chip?

Probably. FM-1s sold since autumn 2026 have a different flash chip, 0xB36014 (the first ones: 0x856014). Your FM-1 is fine – but a firmware that only knows the old chip keeps your saves in RAM, gone when you switch off, and updates from it may fail. Tick Saves on newer FM-1s in the filter for the firmwares that know it (read from each package; the card's pop-up says it too). Already stuck on one that refuses every update? Don't install again and again: the rescue page shows the way, for Windows, Mac and Linux.

My FM-1 is stuck: no installer finds it any more. Is it bricked?

Almost certainly not. The FM-1's chip has a bootloader in ROM that no firmware can overwrite. The FM-1 rescue page goes by what you see: the tools that put a firmware back through it on Windows, Mac and Linux, each saving the whole flash first. On Linux, the Rescue box here does it with two commands.

What happens when you press Install

The page talks to the FM-1 over USB MIDI with the same update protocol as M-VAVE's own updater (first the running firmware stages the new package's update loader, then the loader writes the firmware). The package is checked first (its SHA-256 against the catalogue). Nothing goes to a server: the packages come from this page, mirrored unchanged from each project's GitHub release.
