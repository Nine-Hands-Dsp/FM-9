FM-1 → VIBE FM VST COMING SOON

FM-1 firmwares, converted from their source – unchanged – into one VIBE FM file. The same file plays as a VST3 / AU / CLAP plugin in Ableton Live & co., in the browser and on the VIBE FM. Why converted, not emulated? ↓

  1. Get the VIBE FM VST Plugin.
  2. Pick a firmware – or convert one.
  3. Drop the downloaded .zip onto the VST plugin window.
  4. Open the VST plugin in your DAW, choose it – play.

Install tips – Mac and Windows ask you to allow the beta; Linux packages

Mac · allow the install

  1. macOS stops the .pkg (“not verified”, beta): click Done.
  2. System Settings → Privacy & Security, scroll down → Open Anyway.
    (macOS 14 and older: right-click the .pkg → Open.)
  3. Live: Settings → Plug-Ins, AU / VST3 system folders on → Rescan.

Own firmwares: ~/Library/Application Support/VIBE FM/Firmware

Windows · allow the install

  1. Edge holds the download: … → Keep → Keep anyway.
  2. “Windows protected your PC”: More info → Run anyway, then allow the admin prompt.
  3. Live: Options → Preferences → Plug-Ins, “Use VST3 Plug-In System Folders” on → Rescan.

Own firmwares: %APPDATA%\VIBE FM\Firmware

Linux · install

  1. Ubuntu / Debian: sudo apt install ./vibe-fm-vst_0.8.0-1_amd64.deb
  2. Fedora: sudo dnf install ./vibe-fm-vst-0.7.5-1.x86_64.rpm – or the .tar.gz: ./install.sh (no root).
  3. Raspberry Pi 4 / 5 (ARM64): sudo apt install ./vibe-fm-vst_0.8.0-1_arm64.deb – the same as above, built for ARM.
  4. Bitwig, Reaper, Ardour …: rescan the VST3 / CLAP plugins.

Own firmwares: ~/.local/share/VIBE FM/Firmware

3 · Drop the .zip onto the VST plugin

Drag the downloaded .zip – as it is, no unzipping – onto the VST plugin's window, or choose Add firmware … in the list at the top of the VST plugin: it installs and starts. (Live on the Mac hides VST plugin windows when the Finder comes to the front – use Add firmware …, or drag over Live's icon in the Dock first.) By hand, with VST plugin 0.1: unzip it and put its .wasm and .json into the Firmware folder, then pick it in that list.

  • Mac ~/Library/Application Support/VIBE FM/Firmware (Finder: Go → Go to Folder…)
  • Windows %APPDATA%\VIBE FM\Firmware (type it into the Explorer's address bar)
  • Linux ~/.local/share/VIBE FM/Firmware

Or build your own – the VIBE FM SDK

Write an instrument or effect for VIBE FM directly, in C: the full screen, every control, named DAW parameters, MIDI out, an Editor you lay out – in this VST plugin today, natively on the VIBE FM hardware tomorrow, the same file. The SDK is open – and a converted FM-1 firmware can become a native one: your engine stays, the FM-1 layer goes.

Why converted, not emulated?

To play an FM-1 firmware as a VST3 / AU plugin in your DAW, there are two ways. We chose the one that feels like a real instrument.

Emulator
runs the FM-1's processor, instruction by instruction
CPU loadheavy
Latencyextra buffering
  • Would not run on the VIBE FM itself
  • FM-1 keys and screen, as they were
  • Plays any package, closed ones too
→
Converter VIBE FM SDK
builds the firmware's own source into one VIBE FM file
CPU loada few % of one core
Latencynone added
  • Same music, same firmware – unchanged
  • Fitted to the VIBE's keys and screen
  • One file, three places:
VST3 / AU pluginBrowserVIBE FM

The converter builds on the VIBE FM SDK: an instrument written once in C becomes one .wasm that runs in your DAW, in the browser and on the VIBE FM. That is also why only open-source firmwares can be converted – and why each one is played and checked before it is offered.
